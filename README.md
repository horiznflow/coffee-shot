# The Coffee Shot · Vinyl Lounge Bar — Landing

Static bilingual landing page (vanilla HTML, CSS, JS modules). No build step.

- `/` Spanish (`index.html`)
- `/en/` English (`en/index.html`)

## Run locally

ES modules need a local server (they don't load from `file://`):

```bash
npx serve .
# or
python -m http.server 8000
```

## Structure

```
index.html              Spanish page
en/index.html           English page (same markup, paths prefixed with ../)
favicon.ico             Browser tab icon
robots.txt, sitemap.xml SEO (both languages, with hreflang)
assets/
  icons/                apple-touch-icon.png, icon-512.png (from logo.jpeg)
  images/               logo.png (transparent), hero-poster, barra, cafe, sesiones-bg, tocadiscos, fachada
  images/carta/         4:5 crops for the menu cards (cafe, desayunos, postres, cocteleria)
  video/                hero-pingpong.mp4 (muted hero loop, already forward + reverse)
css/
  tokens.css            Colors, fonts, easing, layout variables
  base.css              Reset + document defaults, .display / .mono / .amber
  layout.css            .sec, .wrap, .label, .h2, .body-lg
  components/           buttons, logo, card (+ photo frames), chips, header (+ language switch)
  sections/             one file per page section (menu.css includes the full digital menu)
  motion.css            Keyframes, hero intro, scroll reveal, reduced-motion overrides
js/
  config.js             EDITABLE: Google reviews URL, Google Place ID, Facebook
  data/menu.js          EDITABLE: full digital menu (ES + EN)
  data/reviews.js       EDITABLE: Google rating, review count and selected reviews (ES + EN)
  main.js               Entry point
  modules/              i18n, carta, reviews, links, menu (mobile nav), hero-video, intro, reveal, parallax, utils
```

## Editing content

Shared data (updates both languages at once):

- **Menu** — `js/data/menu.js`. One category per tab; each item has `name`, `desc`, `price`
  (soles, without "S/"; empty = hidden) and an optional `tag`.
- **Reviews** — `js/data/reviews.js`. Copy `rating` and `count` from Google when they change.
  `text.es` is the original review, `text.en` its translation.
- **Links** — `js/config.js`:
  - `googleReviews`: Google Business profile URL. Empty = Google Maps search for the café.
  - `googlePlaceId`: with a value, the "Escribir una reseña / Write a review" button appears.
  - `facebook`: empty = Facebook links stay hidden.

Page copy (headings, paragraphs, hours, alt texts) lives in the HTML: edit **both**
`index.html` and `en/index.html`. Short UI strings generated by JS are in `js/modules/i18n.js`.

## Domain (SEO)

The pages use the placeholder `https://thecoffeeshot.example` for the canonical URL,
hreflang links, Open Graph and JSON-LD. When the domain is known, replace it everywhere in:
`index.html`, `en/index.html`, `robots.txt`, `sitemap.xml`.

## Hero video

`hero-pingpong.mp4` is the original clip followed by itself reversed, so a plain
`loop` plays back and forth. To regenerate it from a new `hero.mp4`:

```bash
ffmpeg -i hero.mp4 -filter_complex "[0:v]reverse[r];[0:v][r]concat=n=2:v=1:a=0,format=yuv420p[v]" -map "[v]" -an -c:v libx264 -crf 20 -preset slow -movflags +faststart hero-pingpong.mp4
```
